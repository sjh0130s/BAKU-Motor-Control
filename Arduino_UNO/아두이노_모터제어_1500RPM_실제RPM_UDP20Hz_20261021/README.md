# 아두이노 모터 제어 — 실제 엔코더 RPM 피드백 UDP 20Hz (±1500RPM)

- **버전 날짜:** 2026-10-21 (원본 코드 기준)
- **보드:** Arduino UNO + Ethernet Shield + MCP2515 CAN Shield (3단 적층)
- **상태:** 소스 보관용 / Arduino 라이브러리 빌드 및 실차 검증 전
- **구분:** 이 버전의 목표 모터 속도 제한은 **±1500RPM**입니다. 별도로 업로드된 **±4500RPM 버전과 혼동하지 마세요.**

## 파일 안내

- `아두이노_모터제어_1500RPM_실제RPM_UDP20Hz_20261021.ino`: CAN에서 실제 RPM을 읽고 PC로 UDP 전송하는 Arduino 펌웨어
- `PC_모터RPM_UDP20Hz_수신테스트.py`: PC에서 RPM, 수신 타임스탬프, 수신 주파수 확인
- `아두이노_실제RPM_UDP20Hz_변경비교.diff`: 기존 Arduino 코드 대비 변경사항

## 추가 기능

1. 모터 컨트롤러 CAN ID `0x1801D0EF`에서 피드백 수신
2. RPM: CAN 바이트 6~7 Little Endian을 읽어 `raw - 32000` 계산
3. RPM 측정 시점 Arduino `millis()` 기록
4. 새 RPM 피드백이 있는 경우에만 최대 **20Hz(50ms 간격)** UDP 송신
5. UDP: `10.177.21.1:5000`, 데이터 `<int32 RPM, uint32 timestamp_ms>` (Little Endian 총 8바이트), valid 바이트 없음

## 기존 설정 유지

- 목표 RPM 상한: **±1500RPM**
- CAN 모터 명령 송신: 50ms (20Hz)
- 전류 기준: **500A** (원본 코드값 그대로이며 실차 적용 전 안전성 확인 필요)
- ASMS/PC 모드 조건, 모터 전진·후진 로직 유지

> **유의:** UDP 패킷이 최대 20Hz로 전송되도록 설계되었으나, 새 CAN 피드백이 늦게 오거나 네트워크가 불안정하면 실제 주파수는 낮을 수 있습니다. **실차 및 Arduino 컴파일 검증은 수행하지 않았습니다.** 모터 구동 전 전류·속도 제한 및 비상정지 기능 확인이 필요합니다.
